# 4-Week DSA & OOPS Summer Assignment

This assignment is designed to improve your problem-solving skills, coding practices, and consistency.

## General Instructions

1. **Start Date:** The assignment begins on **1 June 2026 (Monday)**.
2. **Duration:** 4 weeks (every new week begins on a Monday).
3. **Daily Quota:** Solve **3 LeetCode problems** daily as per the provided schedule.
4. **Weekly Quota:** Solve **1 OOPS problem** every week.
5. **Workflow:** All DSA problems must first be solved on LeetCode before being uploaded to GitHub.
6. **Discipline:** Daily practice and submissions are compulsory. Avoid keeping pending work for later.

---

## GitHub Submission Guidelines

### Repository Setup
Create a GitHub repository using the following exact naming convention:
`Summer_Assignment_RollNo`
*(Example: `Summer_Assignment_2401920100118`)*
